# Acceptance Criteria - History

- [ ] Campos `id`, `fecha`, `persona_id`, `apellido`, `nombre`, `timestamp` correctos
- [ ] Formatos de `fecha` / `timestamp` correctos
- [ ] Filtro por fecha funcional
